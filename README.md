# CommonGround

A global community platform: communities and discussions, photo/video/poll posts,
reels, stories, follows, real-time chat, voice and video calls, notifications,
events, privacy and safety tools, and a moderation dashboard.

- **Stack:** Django 5 + Django REST Framework + Channels (WebSockets) · React 19 + TypeScript + Vite
- **Project, setup and API:** [`global-community-platform/README.md`](global-community-platform/README.md)
- **Deploying (production and free tier):** [`global-community-platform/docs/DEPLOY.md`](global-community-platform/docs/DEPLOY.md)
